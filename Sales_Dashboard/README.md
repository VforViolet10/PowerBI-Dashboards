# 📊 Sales Dashboard

An interactive **Power BI Sales Dashboard** designed to analyze sales performance and provide insights into revenue, products, customers, and overall business trends.

## 🎯 Key Insights

* Total sales and revenue performance
* Sales trends over time
* Top-performing products
* Customer-wise sales analysis
* Regional/category-wise performance
* Key Performance Indicators (KPIs)

## 🛠️ Tools Used

* Microsoft Power BI
* Power Query
* DAX
* Data Visualization

## 📌 Dashboard Features

* Interactive charts and graphs
* KPI cards
* Filters and slicers
* Trend analysis
* Product and customer analysis

## 📂 Files

* `.pbix` — Power BI dashboard
* Dataset — Source data used for analysis
* Screenshots — Dashboard preview
