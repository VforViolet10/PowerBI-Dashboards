# 🎓 Student Dashboard

An interactive **Power BI Student Dashboard** designed to analyze student performance, attendance, academic progress, and other key educational metrics.

## 🎯 Key Insights

* Overall student performance
* Attendance analysis
* Subject-wise performance
* Student-wise academic trends
* Class/department-wise comparison
* Key Performance Indicators (KPIs)

## 🛠️ Tools Used

* Microsoft Power BI
* Power Query
* DAX
* Data Visualization

## 📌 Dashboard Features

* Interactive charts and graphs
* KPI cards
* Filters and slicers
* Performance comparison
* Academic trend analysis

## 📂 Files

* `.pbix` — Power BI dashboard
* Dataset — Source data used for analysis
* Screenshots — Dashboard preview
