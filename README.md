# 📊 Power BI Dashboards

A collection of interactive **Power BI dashboards and data analytics projects** built to transform raw datasets into meaningful, visually engaging, and actionable insights.

This repository contains dashboards covering different domains and use cases, with a focus on **data cleaning, transformation, visualization, KPI analysis, and business intelligence**.

---

## 🚀 Repository Overview

The dashboards in this repository demonstrate the use of **Microsoft Power BI** for:

* 📈 Interactive data visualization
* 🧹 Data cleaning and preprocessing
* 🔄 Data transformation using Power Query
* 📊 KPI and performance analysis
* 🧮 DAX calculations and measures
* 🔍 Trend and pattern identification
* 🎯 Business and operational insights
* 📑 Interactive reports and dashboards

Each project is based on a different dataset and focuses on solving a specific analytical problem.

* Data type conversion
* Column transformation

### Data Modeling

* Relationships between tables
* Star-schema concepts
* Fact and dimension tables
* Hierarchical data

### DAX

Examples of calculations used across projects include:

```DAX
Total Sales = SUM(Sales[SalesAmount])
```

```DAX
Total Profit = SUM(Sales[Profit])
```

```DAX
Profit Margin = DIVIDE([Total Profit], [Total Sales], 0)
```

## ⚙️ How to Use

1. Clone or download this repository.
2. Install **Microsoft Power BI Desktop**.
3. Navigate to the required dashboard folder.
4. Open the `.pbix` file using Power BI Desktop.
5. If required, update the dataset/file path.
6. Refresh the data.
7. Interact with the dashboard using filters, slicers, and visualizations.

---

## 📌 Notes

* Dataset sources and licenses may vary between dashboards.
* Some dashboards may require the original dataset to refresh successfully.
* `.pbix` files can be relatively large; Git LFS may be used for larger Power BI files.
* Dashboard screenshots are provided for quick preview.
